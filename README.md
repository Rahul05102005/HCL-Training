# HCL Training

This repository contains the work I am completing as part of the HCL Hackathon Training program.

The main focus of this training is to build the project step by step while completing the assigned daily tasks. Each day covers different technical concepts and includes hands-on coding and development work.

## What This Repository Contains

- Daily training tasks
- Java programming exercises
- Maven projects
- Git and GitHub activities
- Project development work
- Hackathon-related implementation

## Daily Tasks

The `Daily_Tasks` folder contains the tasks completed during the training, organized day by day.

Each task is based on the concepts covered during the training and is implemented through practical coding exercises.

## Project

Along with the daily tasks, this repository is used to develop and maintain the project required for the HCL Hackathon Training.

The project is built step by step by applying the concepts and technologies covered during the training.

## Goal

The goal of this training is to successfully complete the daily tasks and build a functional project by applying the concepts learned throughout the program.
