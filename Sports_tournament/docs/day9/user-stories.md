# Day 9 – User Stories
## Project: Sports Tournament Management System

### User Story 1: User Registration and Login
**As a** user,  
**I want** to register and log in securely,  
**So that** I can access features according to my role.

**Story Points:** 5

**Acceptance Criteria:**
- Users can register with valid details.
- Users can log in with valid credentials.
- Invalid credentials display an appropriate error.
- Access is controlled according to user roles.

### User Story 2: Tournament Management
**As an** organizer,  
**I want** to create and manage tournaments,  
**So that** I can organize sports competitions.

**Story Points:** 5

**Acceptance Criteria:**
- Organizers can create tournaments.
- Required tournament details are validated.
- Tournament information can be viewed and updated.

### User Story 3: Team Management
**As an** organizer,  
**I want** to register teams and players,  
**So that** participants can join tournaments.

**Story Points:** 5

**Acceptance Criteria:**
- Teams can be registered.
- Players can be added to teams.
- Invalid or duplicate registrations are handled appropriately.

### User Story 4: Match Scheduling
**As an** organizer,  
**I want** to schedule matches,  
**So that** teams know when and where they will play.

**Story Points:** 8

**Acceptance Criteria:**
- Matches can be scheduled for tournaments.
- Match dates, teams, and venues are recorded.
- Scheduling conflicts are handled appropriately.

### User Story 5: Live Match Scoring
**As a** referee,  
**I want** to update match scores,  
**So that** participants can follow match progress.

**Story Points:** 8

**Acceptance Criteria:**
- Authorized referees can update scores.
- Score updates are associated with the correct match.
- Invalid score updates are rejected.

### User Story 6: Match Finalization
**As a** referee,  
**I want** to finalize completed matches,  
**So that** official results can be recorded.

**Story Points:** 5

**Acceptance Criteria:**
- Completed matches can be finalized.
- Match results are saved.
- Unauthorized users cannot finalize matches.

### User Story 7: Tournament Standings
**As a** participant,  
**I want** to view tournament standings,  
**So that** I can understand team rankings and progress.

**Story Points:** 5

**Acceptance Criteria:**
- Standings are displayed for a tournament.
- Rankings reflect recorded match results.
- Users can view the relevant tournament standings.

### User Story 8: Tournament Dashboard
**As an** organizer,  
**I want** to view tournament information on a dashboard,  
**So that** I can monitor tournaments and match activity.

**Story Points:** 5

**Acceptance Criteria:**
- The dashboard displays relevant tournament information.
- Match and tournament summaries are accessible.
- Dashboard information is presented clearly.
